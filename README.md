https://sk910711-max.github.io/sameer-khan-academy/

## Search engine files

- `robots.txt` allows public crawling and points to the XML sitemap.
- `sitemap.xml` lists the canonical homepage URL.
- The homepage contains a canonical URL, index/follow robots directives, Open Graph and Twitter metadata, and JSON-LD structured data.

Google may take time to crawl and index the site. Search Console ownership verification and sitemap submission can be completed after the public page is live.
